# Anime cover samples

These three compressed cover images are used only to prove that the media
renderers produce self-contained SVGs that GitHub can display through its image
proxy. The generator converts them to `data:image/jpeg;base64,...` URIs.

Sources:

- [Shinsekai yori](https://anilist.co/anime/13125/Shinsekai-yori/)
- [Mononoke](https://anilist.co/anime/2246/Mononoke/)
- [DAN DA DAN](https://anilist.co/anime/171018/DAN-DA-DAN/)
